## CREW BRIEFING / QUICK FIELD MATH REFRESHER

* **Roof Pitch / Slope:** Pitch is expressed as **Rise over Run** (e.g., $6/12$ means 6 inches of vertical rise for every 12 inches of horizontal run). Total Run is half the total building span.
* **On-Center (O.C.) Stud Count:** Formula for wall framing is $\text{Total Length (in inches)} \div \text{Spacing (16") } + 1 \text{ (Starter Stud)} + \text{Waste/Corners}$.
* **Stair Geometry:** Ideal stair rise per step is **$7" \text{ to } 7\ 1/2"$**. Total Rise = floor-to-floor height in inches. Number of Risers = Total Rise $\div$ Target Rise (rounded to nearest whole number).

                  |                    | 108-3/4"

  <------------------------------------>

### Crew Instructions:

*Number of Risers:* **[ Blank 1 ]**
2. **Calculate Exact Riser Height:**
Divide total floor-to-floor height ($108\ 3/4"$) by the whole number of risers from Blank 1.
*Exact Riser Height (to nearest $1/16"$):* **[ Blank 2 ]**
3. **Calculate Total Staircase Run:**
Building code requires a minimum tread depth of **$10"$**. The number of treads is always **$\text{Risers} - 1$**. Calculate total horizontal run of the stairs.

## ACTIVITY SET 5: WALL FRAMING STUD TAKEOFF & SPACING

**Task:** Calculate the total stud count and top/bottom plate stock for a load-bearing exterior wall.

```
   <===============================================================>
   ||  DOUBLE TOP PLATE                                           ||
   ||=============================================================||
   ||   |   |   |   |   |   |   |   |   |   |   |   |   |   |   | ||
   ||   |   |   |   |   |   |   |   |   |   |   |   |   |   |   | ||
   ||   |   |   |   |   |   |   |   |   |   |   |   |   |   |   | ||
   ||=============================================================||
   ||  SINGLE BOTTOM PLATE                                        ||
   <===============================================================>
   <------------------ Wall Length: 42' 8" ------------------------>
   <---- Stud Spacing: 16" O.C. ---->

```

### Crew Instructions:

1. **Calculate Common Stud Count:**
Wall length is **$42'\ 8"$**.
* Convert wall length entirely into inches.
* Divide by **$16"$** on-center spacing.
* Add **$1$** starter stud.
*Base Stud Count:* **[ Blank 4 ]**


2. **Account for Framing Details & Waste:**
Add $4$ studs for corners/intersections, plus $10\%$ extra for bad stock/waste. (Round up to the next whole stud).
*Total $2\times6\times92\ 5/8"$ Studs to Order:* **[ Blank 5 ]**
3. **Plate Linear Footage:**
Wall uses a **single bottom plate** and **double top plate** (3 plates total).
Multiply wall length ($42'\ 8"$) by 3.
*Total Linear Feet of Plate Material:* **[ Blank 6 ]**

## ACTIVITY SET 6: ROOF RAFTER LENGTH & COMMON PITCH

**Task:** Find the total rafter length (common rafter) for a gable roof truss order.

```
                           / \
                          /   \
                         /     \  Rafter Length = [ Blank 8 ]
                        /       \
                       /  Rise   \
                      /   [Bk 7]  \
                     /|           |\
                    /_|___________|_\
                    <----> <------>
                     Run     Run
                    <-- Span: 28' -->

```

### Crew Instructions:

1. **Determine Total Run:**
Total building span is **$28'\ 0"$**. Roof overhang is $0$ for this layout.
*Total Run (Half of Span):* **[ Blank 7 ]**
2. **Calculate Total Rise:**
The architect specified a **$6/12$ roof pitch** (6 inches of rise per 12 inches of run).
Multiply your Total Run (in feet) by $6"$.
*Total Roof Rise:* **[ Blank 8 ]**
3. **Calculate Line Rafter Length:**
Use the Pythagorean Theorem ($a^2 + b^2 = c^2$) where $a = \text{Run (ft)}$ and $b = \text{Rise (ft)}$.
Calculate $c$ (Rafter Length in feet and inches, rounded to nearest $1/16"$).
*Total Rafter Length:* **[ Blank 9 ]**
