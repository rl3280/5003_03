Your goal is to:

- Choose something meaningful that you want to design and build (a small app, interface, or expressive webpage)

- Use HTML and CSS to bring it to life — with a clear layout, structure, and styling

- Begin to think about interactivity, even if you're not coding it yet

#### Part 1 – AI Learning

Use AI tools (like ChatGPT, Copilot, or another assistant) to:

- Generate or refine layout ideas

- Get help translating design into HTML/CSS

- Explore different styling options (box model, spacing, color, hierarchy)

- Ask questions when you're unsure what to do or how something works

**Document your process** — What did the AI give you? What did you keep or change? What did you learn?

#### Part 2 – Design

Pick something you want to make. This can be simple — a:

- To-do list

- Pet profile card

- Weather dashboard

- Mood tracker

- Event flyer

- Journal or daily log

- Interface for a simple game or app

Start by imagining the **layout and experience**. How will it be organized? What do you want someone to see or do when they visit it?

You can begin by:

Sketching your layout on **paper or a whiteboard**

Creating a quick wireframe in **Figma** (or another tool you like)

Blocking out your idea directly in **HTML/CSS** as a rough draft

Your final design should reflect:

**Clear layout and structure** using semantic HTML

**Styling** with CSS (internal or external — your choice)

At least one element **meant to be interactive**, even if it's not functional yet (e.g., a button, input form, or toggle). Just describe what it *should* do — we’ll learn how to make it work with JavaScript soon.

This is your chance to combine creativity and structure — to think like a designer and communicate through layout and visual logic.

#### Part 3 – Code

Build a working version of your layout using:

- HTML for structure
- CSS for styling
You may use Codepen, JSFiddle, or other online sharable editor resources.

Focus on:

- Translating your design clearly into code

- Clean organization of tags, classes, and styles

- Creating something you could later make interactive with JavaScript
